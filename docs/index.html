Funciones confirmadas

Control de entrenamiento sin fricción.

La app está pensada para abrir la rutina durante el entrenamiento, marcar series y consultar el avance del día sin depender de servicios externos.

Seguimiento de rutinas

Rutina semanal con días y ejercicios para organizar cada sesión.

Rondas por ejercicio

Casillas táctiles para completar o desmarcar cada serie de un ejercicio.

Progreso diario

Resumen de hoy, historial, días entrenados, series totales y rachas.

Local-first

El progreso se guarda en Room/SQLite dentro del dispositivo Android.

Uso móvil rápido

Interfaz Compose optimizada para consultar y marcar durante la sesión.

Backup JSON

Exporta e importa tus datos o rutinas mediante archivos JSON.

Cómo funciona

Cuatro pasos para entrenar y registrar.

1

Descarga la APK

Usa el botón principal y guarda el archivo en tu Android.

2

Instala la app

Abre el archivo y permite la instalación desde el navegador si Android lo solicita.

3

Abre tu rutina

Consulta el día actual o edita los ejercicios según tu planificación.

4

Marca cada ronda

Completa series, revisa el porcentaje del día y conserva tu historial local.
