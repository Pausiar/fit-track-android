Política de privacidad

Última actualización: 23 de octubre de 2026 · versión 2.0

Esta política explica qué datos trata Fit Track, tanto la aplicación Android como esta web de descarga. El principio de diseño es sencillo: la app funciona en local y la web no recoge datos personales directamente.

1. Responsable del tratamiento

  • Titular: Pausiar, proyecto personal de desarrollo de software sin actividad comercial.
  • Contacto para privacidad: issues del repositorio en GitHub. Este es el canal habilitado para solicitudes relacionadas con protección de datos.
  • Naturaleza: proyecto gratuito, sin venta de productos, sin pagos y sin ánimo de lucro.

No se ha designado un Delegado de Protección de Datos porque no concurren los supuestos del artículo 37 del RGPD.

2. Ámbito de esta política

Se aplica a:

  • La web pausiar.github.io/fit-track-android y sus páginas legales y de descarga.
  • La aplicación Android Fit Track (paquete com.pausiar.fit), versión 1.1.0 y posteriores, distribuida mediante APK firmada.

3. Datos tratados por esta web

La web es estática. No tiene formularios propios, registro, área privada, comentarios, analítica, píxeles publicitarios ni cookies no técnicas. Tampoco carga fuentes, scripts o imágenes desde dominios de terceros: todos los recursos son propios o se sirven desde el mismo dominio.

El alojamiento corre a cargo de GitHub Pages. GitHub puede registrar datos técnicos de la conexión (dirección IP, fecha y hora, agente de usuario, recurso solicitado) para prestar el servicio, mantener la seguridad y prevenir abusos. Esos registros los trata GitHub conforme a su propia política de privacidad y no se comparten con el titular de esta web.

  • Finalidad: servir la web y los archivos, seguridad y prevención de abusos.
  • Base jurídica: interés legítimo en mantener el sitio disponible y seguro (art. 6.1.f RGPD), sin perfilado.
  • Conservación: la que aplique GitHub a sus registros técnicos; esta web no mantiene una base de datos propia.

4. Datos tratados por la aplicación

Fit Track está diseñada para funcionar sin conexión y sin cuenta. La rutina, los ejercicios, las notas, el progreso por fecha y el historial se almacenan únicamente en una base de datos Room/SQLite del dispositivo.

  • El manifiesto Android no declara el permiso INTERNET. La app no envía datos a servidores del titular ni de terceros.
  • No hay login, sincronización, publicidad, compras integradas ni SDK de analítica.
  • Las copias de seguridad automáticas de Android están desactivadas (android:allowBackup="false") para evitar que los datos se suban a servicios de copia en la nube.
  • La exportación e importación JSON solo se ejecuta cuando la persona usuaria la inicia desde Ajustes y elige un archivo mediante el selector del sistema.
  • Al desinstalar la app se eliminan sus datos locales, salvo que previamente se haya exportado una copia.

La app no solicita permisos de ubicación, contactos, cámara, micrófono, teléfono ni almacenamiento externo. No trata categorías especiales de datos del artículo 9 del RGPD. Los datos de entrenamiento son datos personales en la medida en que permitan identificar a una persona, pero permanecen bajo su control en el dispositivo.

5. Finalidades y bases jurídicas

  • Facilitar la descarga y el uso local de la app: ejecución de la relación solicitada por la persona usuaria (art. 6.1.b RGPD) e interés legítimo en publicar un proyecto gratuito (art. 6.1.f).
  • Mantener la web disponible y segura: interés legítimo (art. 6.1.f), limitado a registros técnicos del alojamiento.
  • Atender comunicaciones voluntarias: consentimiento al abrir un issue o contactar (art. 6.1.a) o medidas precontractuales, según el caso.

No se toman decisiones automatizadas con efectos jurídicos ni se elaboran perfiles publicitarios.

6. Destinatarios y transferencias internacionales

No se venden, alquilan ni ceden datos personales. El único proveedor implicado en la web es GitHub (GitHub, Inc. / Microsoft), que actúa como encargado o responsable independiente del alojamiento. GitHub puede tratar datos fuera del Espacio Económico Europeo al amparo del Marco de Privacidad de Datos UE-EE. UU. o de cláusulas contractuales tipo. Puedes consultar su política en docs.github.com.

La app no tiene destinatarios: no hay servidores, APIs ni terceros que reciban los datos de entrenamiento.

7. Conservación

  • Web: no se conservan datos en una base propia. Los registros técnicos dependen de GitHub y de sus plazos de retención.
  • App: los datos permanecen en el dispositivo hasta que se borren desde Ajustes, se restablezca la app o se desinstale. El titular de la web no tiene acceso a ellos.
  • Comunicaciones: los issues o mensajes se conservan en GitHub mientras el repositorio esté público y la persona no solicite su eliminación.

8. Derechos de las personas usuarias

Puedes ejercer los derechos de acceso, rectificación, supresión, oposición, limitación del tratamiento y portabilidad cuando proceda. Para ello, abre una solicitud en el repositorio de GitHub indicando el derecho que deseas ejercer y un medio de contacto. Si no quieres publicar datos personales en un issue, dilo expresamente para que se habilite un canal privado. También puedes solicitar la retirada de un issue que contenga datos personales.

Si consideras que el tratamiento no se ajusta a la normativa, puedes reclamar ante la Agencia Española de Protección de Datos (aepd.es), sin perjuicio de otros recursos.

9. Menores de edad

La app es una herramienta de registro deportivo y no está dirigida específicamente a menores de 14 años. No recoge datos de menores porque no hay registro ni servidor. Si un menor utiliza la app, será bajo la supervisión de su madre, padre o tutor legal.

10. Seguridad

La APK se distribuye firmada con el certificado de release del proyecto y acompañada de su SHA-256 y huella de certificado para que pueda verificarse. La app aplica minimización de permisos y funciona sin red. Ningún sistema es infalible: si detectas un problema de seguridad, comunícalo de forma responsable a través del repositorio antes de hacerlo público.

11. Cambios en esta política

Esta política puede actualizarse si cambian la app, la web o la normativa. La fecha de la cabecera indica la última revisión. Los cambios sustanciales se anunciarán en el repositorio. El uso continuado de la web o de la app después de una actualización implica la aceptación de la versión vigente, sin perjuicio de los derechos que correspondan.

12. Contacto

Para cualquier duda sobre privacidad, abre un issue en github.com/Pausiar/fit-track-android/issues. No se publica una dirección postal ni un correo electrónico por tratarse de un proyecto personal sin actividad comercial; si en el futuro se habilita un canal específico, se actualizará esta página.

Resumen en una frase: la web no recoge datos personales directamente y la app guarda todo en tu móvil, sin permiso de Internet y sin copias automáticas en la nube.
