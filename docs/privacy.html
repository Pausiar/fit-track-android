2. Datos recogidos por esta web

La web de descarga es estática, no incluye formularios propios, analytics, tracking, embeds de terceros ni cookies no técnicas. La web no recoge datos personales directamente salvo los que el usuario facilite voluntariamente mediante enlaces externos o medios de contacto.

GitHub Pages y GitHub pueden tratar datos técnicos de acceso según sus propias condiciones y políticas cuando visitas páginas o descargas archivos alojados en GitHub.

3. Datos tratados por la aplicación

Según el código revisado, la aplicación almacena los datos de entrenamiento localmente en el dispositivo mediante Room/SQLite. El manifiesto Android no declara permiso de Internet y el proyecto no incluye backend ni login.

4. Finalidad y base legal

  • Mantener una página informativa y facilitar la descarga de la APK: interés legítimo del responsable en publicar el proyecto.
  • Responder comunicaciones iniciadas voluntariamente por el usuario: consentimiento o medidas precontractuales, según el caso.
  • Permitir el funcionamiento local de la app: ejecución de la funcionalidad solicitada por el usuario en su dispositivo.

5. Conservación

La web no conserva una base de datos propia con datos personales. Los datos de entrenamiento permanecen en el dispositivo del usuario hasta que este los borre, resetee la app o desinstale la aplicación.

6. Destinatarios y servicios externos

No se han detectado servicios de analítica, publicidad o seguimiento en la web. La descarga y el repositorio pueden implicar acceso a GitHub, sujeto a sus propias políticas.
