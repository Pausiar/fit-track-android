Instalación

Cuatro pasos, sin cuenta.

Android mostrará avisos de seguridad propios de cualquier instalación fuera de Play Store. Son esperados y no indican que el archivo esté dañado.

  1. Descarga el APK. Pulsa el botón principal y espera a que termine la descarga. Comprueba que el tamaño coincide con 11,2 MB.
  2. Autoriza la instalación. Abre el archivo desde la notificación o el gestor de archivos. Si Android lo pide, permite «Instalar apps desconocidas» para ese navegador o gestor.
  3. Confirma el aviso de Play Protect. Puede aparecer «Analizar la app» o un aviso de desarrollador desconocido. Elige instalar solo si has verificado el SHA-256.
  4. Abre Fit Track. Concede los permisos que muestra la app (no solicita Internet, ubicación, contactos ni almacenamiento). Empieza a marcar series.

Requisitos

  • Android 8.0 o superior (API 26+).
  • Espacio libre: unos 25 MB contando instalación y datos.
  • No requiere Google Play Services, cuenta de Google ni conexión permanente.
  • La descarga inicial sí necesita conexión; la app funciona después sin ella.

Si Android bloquea la instalación

  • Comprueba que has permitido instalar apps desconocidas para el navegador usado.
  • Desactiva temporalmente «Play Protect → Analizar apps» solo si confías en el archivo y has verificado el hash.
  • No instales el APK desde enlaces reenviados: descárgalo siempre desde esta página.

Verificación

Comprueba el archivo antes de instalar.

El SHA-256 identifica exactamente el APK publicado. Si el valor calculado no coincide, borra el archivo y vuelve a descargarlo desde esta página.

1 · Calcula el SHA-256

Windows (PowerShell):

Get-FileHash .\fit-track-1.1.0.apk -Algorithm SHA256

macOS / Linux:

sha256sum fit-track-1.1.0.apk

Android (Termux):

sha256sum fit-track-1.1.0.apk

Compara el resultado con el hash publicado. También puedes descargar el archivo .sha256 y ejecutar sha256sum -c fit-track-1.1.0.apk.sha256.

2 · Comprueba la firma

El certificado debe ser CN=Fit Track, OU=Pausiar, O=Pausiar, C=ES. Huella SHA-256:

5F:18:5F:6E:D8:8A:57:35:7E:0C:52:10:07:A6:44:F7:BD:1C:7C:56:02:16:10:B2:CB:BB:38:F3:40:3B:85:82

Con Android SDK Build-Tools:

apksigner verify --print-certs fit-track-1.1.0.apk

La salida debe incluir Verifies, el DN indicado y la misma huella. La build actual usa el esquema de firma APK v2, válido para Android 8.0+.

Certificado público para comparar: fit-track-release.pem.

Qué significa «la APK no es segura». Android y Play Protect muestran advertencias genéricas con apps instaladas fuera de Play Store, incluso si la firma es válida. Una firma release evita el error de certificado de depuración y permite actualizaciones coherentes, pero no elimina el aviso de «origen desconocido»: eso solo lo hace la distribución mediante Google Play. Esta web publica el hash y la huella para que puedas distinguir un archivo oficial de una copia modificada.

Problemas frecuentes

Si algo no funciona.

«App no instalada» o «Error de análisis»

Suele indicar un archivo incompleto o una versión anterior con firma distinta. Borra el APK, vuelve a descargarlo y comprueba el SHA-256. Si tenías la 1.0, desinstálala primero. También puede ocurrir si el dispositivo no tiene Android 8.0 o superior.

Play Protect bloquea la instalación

Es un aviso de desarrollador no verificado por Google. Verifica el hash y la firma; si coinciden, puedes continuar desde «Más detalles → Instalar de todos modos». No desactives Play Protect de forma permanente ni instales APKs de origen desconocido.

La descarga se corta o va lenta

El archivo pesa unos 11,2 MB y se sirve desde GitHub Pages. Reintenta la descarga; si el problema persiste, usa la release de GitHub como espejo. No uses gestores que modifiquen el archivo.

¿Puedo volver a la versión anterior?

No se recomienda: la 1.0 está firmada en debug y no recibe mantenimiento. Si necesitas conservar datos, exporta el JSON y contacta a través del repositorio antes de cambiar de versión.
