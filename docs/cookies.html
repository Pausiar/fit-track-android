Política de cookies

Última actualización: 23 de octubre de 2026 · versión 2.0

Esta web no utiliza cookies propias ni tecnologías equivalentes. No hay banner de cookies porque no se instala ni se lee ningún identificador en el navegador.

1. Qué son las cookies y tecnologías similares

Las cookies son pequeños archivos que un sitio guarda en el navegador. También existen tecnologías equivalentes como localStorage, sessionStorage, IndexedDB, píxeles de seguimiento, huellas de dispositivo o almacenamiento en caché con identificadores.

2. Qué utiliza esta web

Cookies propiasNinguna
Cookies de tercerosNinguna
Analítica o píxelesNinguno
localStorage / sessionStorageNo se usan
Fuentes, CDN o embeds externosNinguno
Publicidad o perfiladoNinguno

El único JavaScript propio hace tres cosas: animaciones de aparición con IntersectionObserver, lectura del archivo local release.json para mostrar la versión y el checksum, y la función de copiar al portapapeles cuando se pulsa un botón. No guarda identificadores ni preferencias en el navegador.

3. Alojamiento en GitHub Pages

El sitio se aloja en GitHub Pages. Como cualquier servidor web, GitHub recibe la petición HTTP y puede registrar datos técnicos (IP, agente de usuario, recurso y fecha) para operar el servicio y protegerlo frente a abusos. Esos registros no son cookies instaladas por esta web y se rigen por la política de privacidad de GitHub.

4. Qué pasa al descargar la APK

La descarga es una petición HTTP normal al mismo dominio. No se usa un gestor de descargas con cookies, no se abre una ventana emergente y no se redirige a un acortador. GitHub Pages puede registrar la petición del archivo como cualquier otro recurso.

5. Cómo gestionar cookies en el navegador

Aunque esta web no instala cookies, puedes revisar o borrar las de otros sitios desde la configuración de tu navegador:

  • Chrome: Configuración → Privacidad y seguridad → Cookies y otros datos de sitios.
  • Firefox: Ajustes → Privacidad y seguridad → Cookies y datos del sitio.
  • Safari: Ajustes → Privacidad → Gestionar datos de sitios web.
  • Edge: Configuración → Cookies y permisos del sitio.

6. Cambios

Si en el futuro se añade una función que requiera cookies o almacenamiento local, se actualizará esta página y, cuando la normativa lo exija, se solicitará consentimiento previo. La fecha de la cabecera refleja la última revisión.

7. Contacto

Para dudas sobre cookies o privacidad, abre un issue en github.com/Pausiar/fit-track-android/issues.

No hay nada que aceptar: esta web no usa cookies ni almacenamiento del navegador, por lo que no necesita un banner de consentimiento.
