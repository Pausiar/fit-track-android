Política de cookies

Última actualización: 4 de junio de 2026. Este texto es una plantilla básica para España/UE y debe ser revisado por un profesional antes de uso definitivo.

1. Qué son las cookies

Las cookies son pequeños archivos que un sitio web puede guardar en el navegador para recordar información técnica o preferencias.

2. Cookies utilizadas por esta web

Esta web estática no utiliza cookies propias, cookies publicitarias, analytics, tracking, píxeles, embeds de terceros ni scripts externos de seguimiento.

La única funcionalidad JavaScript incluida muestra animaciones de aparición con IntersectionObserver y no guarda identificadores ni preferencias en el navegador.

3. Banner de cookies

No se muestra banner de cookies porque no se cargan cookies no técnicas ni tecnologías equivalentes que requieran consentimiento previo.

4. GitHub Pages y descargas externas

El alojamiento en GitHub Pages y los enlaces al repositorio o descargas de GitHub pueden estar sujetos a las políticas de GitHub. Consulta la documentación y políticas de GitHub para más información.

5. Gestión desde el navegador

Puedes bloquear o eliminar cookies desde la configuración de tu navegador. Las rutas habituales están en los apartados de privacidad o seguridad de Chrome, Firefox, Safari, Edge u otros navegadores.
